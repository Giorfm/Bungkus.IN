# Bungkus.In
Bungkusin adalah sebuah platform digital (web/aplikasi) yang menghubungkan konsumen dengan restoran/toko yang memiliki kelebihan makanan di akhir hari. Makanan ini akan dijual dengan harga diskon minimal 50%-70% dari harga normal. Pembeli memesan dan membayar lewat aplikasi, lalu mengambilnya sendiri (Pick-up) ke toko pada jam tutup yang ditentukan.
